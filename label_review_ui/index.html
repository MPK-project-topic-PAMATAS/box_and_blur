Supports split/images + labels, images/split + labels/split, nested street folders, and COCO JSON with linked images. When both formats exist, saving keeps them synchronized.

A quick guide

  1. Open a dataset folder. Search by full or partial image filename, label path, class, or COCO annotation ID.
  2. Use B to draw a box. Use V to select, move and resize boxes. Change classes in the right panel. Delete removes the selected box.
  3. Use the wheel to zoom around the pointer. Hold Space and drag to pan. Fit shows the whole frame; 1:1 shows original pixel scale.
  4. Use G to draw blur regions, choose a strength, then preview. Blur only changes pixels when saved.
  5. Ctrl+S saves. Enter saves any edits, marks the image reviewed, and advances. ← / → navigate. Unreviewed buttons skip finished images. Ctrl+Z / Ctrl+Y undo / redo unsaved edits.

Empty labels are valid negatives. Saving an image with no boxes creates or preserves an empty YOLO label and removes its COCO boxes.

Each save backs up changed originals and records a receipt under the tool's .label_review folder. Full filenames, image dimensions, splits and unrelated COCO metadata are preserved. Files edited elsewhere must be reloaded before saving.

Detection bounding boxes are supported. Polygon and pose annotations are protected against incompatible box-only edits. Choose Gaussian blur or pixelation and inspect the preview before sharing images.
